API Titanic Evacuation Optimizer

Simulador completo de planos de evacuação baseado em dados históricos do Titanic, implementado com FastAPI e otimização via simulação Monte Carlo.

Início rápido Modelos de dados Mapa de endpoints Otimização Consultas analíticas Boas práticas

🚀 Início rápido

Passo a passo para executar o projeto localmente. Recomendamos Python 3.10+.

Configuração

  1. (Opcional) Crie um ambiente virtual: python -m venv .venv
  2. Instale dependências: pip install -r requirements.txt

Execução

  1. Inicie o servidor: uvicorn main:app --reload --port 8007
  2. Acesse http://localhost:8007 para visualizar esta documentação embutida.

Dependências-chave

  • fastapi · API moderna com tipagem
  • pandas · Manipulação de dados históricos
  • pydantic · Validação de payloads
  • uvicorn · Servidor ASGI
Usando outra porta ou host

Ajuste a flag --port e, se necessário, --host. Exemplo: uvicorn main:app --reload --host 0.0.0.0 --port 8000. Atualize também as URLs de consumo da API.

🧱 Modelos de dados

Estruturas principais utilizadas para entrada e saída do endpoint de otimização.

EvacuationConstraints

  • total_lifeboat_capacity · capacidade combinada dos botes (int)
  • max_evacuation_time · tempo máximo em minutos (int)
  • crew_members · tamanho da tripulação (int)
  • priority_system · enum (women_children_first, class_based, age_based, disability_first, random, optimal_survival)
  • consider_mobility · considera mobilidade reduzida (bool)
  • panic_factor · fator de pânico (0–1, float)

EvacuationRequest

  • constraints · objeto EvacuationConstraints
  • optimize_for · objetivo da simulação (max_survivors | min_time | fairness | balanced)
  • simulation_runs · número de execuções Monte Carlo (int)

EvacuationPlan · resposta

  • plan_id · identificador único
  • total_evacuated, survival_rate, total_time_minutes
  • fairness_score · 0–1
  • lifeboat_assignments · passageiros por bote e ordem de lançamento
  • evacuation_phases · fases sugeridas da operação
  • optimization_metrics, recommendations

🛟 Endpoint de otimização

Principal recurso da API. Executa simulações Monte Carlo e devolve um plano completo de evacuação.

POST /api/v1/optimize/evacuation-plan

Campos obrigatórios

  • constraints.total_lifeboat_capacity · capacidade total dos botes
  • constraints.max_evacuation_time · tempo máximo (min)
  • constraints.priority_system · estratégia (enum)
  • constraints.panic_factor · intensidade do pânico (0–1)
  • constraints.consider_mobility · considerar mobilidade
  • optimize_for · objetivo (default: max_survivors)
  • simulation_runs · número de simulações
Exemplo de payload JSON 
{
    "constraints": {
        "total_lifeboat_capacity": 1178,
        "max_evacuation_time": 120,
        "priority_system": "women_children_first",
        "panic_factor": 0.15,
        "consider_mobility": true
    },
    "optimize_for": "max_survivors",
    "simulation_runs": 500
}
Consumindo com requests 
import json
import requests

url = "http://localhost:8000/api/v1/optimize/evacuation-plan"
payload = {
        "constraints": {
                "total_lifeboat_capacity": 1178,
                "max_evacuation_time": 120,
                "priority_system": "women_children_first",
                "panic_factor": 0.15,
                "consider_mobility": True
        },
        "optimize_for": "max_survivors",
        "simulation_runs": 500
}

response = requests.post(url, json=payload)
print(response.status_code)
print(json.dumps(response.json(), indent=2, ensure_ascii=False))

Saída principal

  • total_evacuated, survival_rate, total_time_minutes
  • fairness_score · equilíbrio entre classes e gêneros
  • lifeboat_assignments · passageiros designados por bote
  • evacuation_phases · roteiro sugerido
  • recommendations · ações sugeridas quando indicadores estão baixos
  • optimization_metrics · parâmetros internos, score e taxa de utilização da frota
